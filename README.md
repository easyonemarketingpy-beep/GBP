# Easy One Rank

Plataforma de gestao e ranqueamento de Perfis da Empresa no Google (Google
Business Profile), vendida a agencias e a negocios locais.

Projeto **independente** do Easy One Chatbot: repositorio proprio, projeto
proprio no Lovable, deploy proprio. Um problema num nao derruba o outro.

O que os dois compartilham e **uma coisa so**: o banco do Supabase, e por
consequencia o login e a tabela de contas. E isso que faz o menu da logo, em
app.easyonemarketing.com, saber quais produtos aquela pessoa comprou.

- `db/` migracoes SQL, numeradas, para rodar no SQL Editor do Supabase
- `docs/` prompts do Lovable e documentacao de decisao

Estado: schema inicial. Nenhuma tela construida ainda.
